## ADDED Requirements

### Requirement: 管理员重置员工密码
系统 SHALL 支持管理员为指定员工重置登录密码。

#### Scenario: 成功重置密码
- **WHEN** 管理员对某员工触发密码重置操作
- **THEN** 系统生成新的 8 位随机密码，BCrypt 加密后更新数据库，明文密码通过 API 响应返回给管理员

#### Scenario: 二次确认
- **WHEN** 管理员点击密码重置按钮
- **THEN** 系统前端弹出确认对话框，提示"确认重置员工 [员工姓名] 的密码？"，管理员确认后才执行重置

#### Scenario: 非员工用户不可重置
- **WHEN** 管理员尝试对 role 非 EMPLOYEE 的用户重置密码
- **THEN** 系统拒绝并提示"仅可重置员工账户密码"

#### Scenario: 重置后原密码失效
- **WHEN** 员工密码被管理员重置
- **THEN** 员工原密码立即失效，仅能使用新密码登录

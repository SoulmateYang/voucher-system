## ADDED Requirements

### Requirement: 登录成功后到期提醒
系统 SHALL 在员工 H5 登录成功后自动检查即将到期的卡券，如有则弹窗提醒。

#### Scenario: 登录成功且有即将到期的卡券
- **WHEN** 员工登录成功获取 token 后，后端返回即将到期的卡券数量大于 0
- **THEN** 系统弹出 Dialog 提醒，标题为"卡券到期提醒"，内容包含"N张卡券将在7天内过期，请及时使用"，并提供"我知道了"按钮

#### Scenario: 点击"我知道了"关闭弹窗
- **WHEN** 员工在到期提醒弹窗中点击"我知道了"
- **THEN** 系统关闭弹窗，正常跳转到卡券列表页

#### Scenario: 登录成功但无即将到期的卡券
- **WHEN** 员工登录成功获取 token 后，后端返回即将到期的卡券数量为 0
- **THEN** 系统不弹出提醒，直接跳转到卡券列表页

#### Scenario: 到期查询接口调用失败
- **WHEN** 登录成功但到期查询接口返回错误或网络异常
- **THEN** 系统静默处理错误，不弹出提醒，不阻断正常跳转
